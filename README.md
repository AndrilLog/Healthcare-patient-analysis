# 🏥 Healthcare Patient Analysis

An end-to-end healthcare data analytics project demonstrating the complete analytics workflow, from data cleaning and exploratory data analysis (EDA) in Python to interactive dashboard development in Power BI.

---

## 📖 Project Overview

This project analyses healthcare patient data to uncover trends in patient demographics, medical conditions, hospital admissions, billing, and length of stay. The dataset was cleaned and explored using Python before being transformed into an interactive Power BI dashboard for business reporting.

---

## 🎯 Objectives

- Clean and prepare healthcare data for analysis.
- Perform exploratory data analysis (EDA) to identify trends and patterns.
- Engineer additional features to support analysis.
- Develop an interactive Power BI dashboard.
- Present insights that support data-driven decision making.

- Gender Distribution
- Admissions by Year
- Admissions by Season

---

## 🔍 Key Insights

- The dataset contains **54,966 patient records** after data cleaning.
- Male and female patient counts are almost equally distributed.
- The average patient age is **51.54 years**.
- The average hospital stay is **15.5 days**.
- The average billing amount is approximately **25.54K**.
- Patient counts are fairly balanced across all recorded medical conditions.
- Hospital admissions remain relatively stable between **2020 and 2023**, while **2024 records fewer admissions**, likely because it represents incomplete yearly data.
- No significant seasonal variation in patient admissions is observed.
